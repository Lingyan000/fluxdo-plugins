# 动态订阅

在市场安装并启用后，从元宇宙打开「动态订阅」。在右上角添加论坛用户名，或导入自己关注的用户。可在应用底栏设置中添加「订阅」。按用户、发帖、回复、赞、回应、Boost 筛选，点击记录打开原生话题，点击管理列表中的用户名打开个人页。

最多订阅 50 人，每人保留最近 10 条；首次收到的记录只建立基线。开启自动更新后按所选间隔轮流检查一人。后台刷新和新动态通知分别授权，默认关闭。移动系统自行决定唤醒时间，不提供实时推送；桌面需要应用进程运行。可在插件管理停止任务、关闭通知或清空全部数据。

需要支持 schema 12 的 FluxDO。开发时用 `node tools/package.mjs plugins/activity-feed dist/activity-feed-1.0.0.fluxplugin` 构建，真实宿主使用同一 `.fluxplugin` 运行 QuickJS 和存储回归。

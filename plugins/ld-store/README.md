# LD士多

LD士多的 FluxDO 原生插件，支持商品搜索与筛选、详情和评论互动、补货订阅、登录、报价、订单创建、LDC 收银台、订单查询与交付内容，以及优惠券、收藏、售后和举报记录。

当前版本为 2.7.1，清单使用 schema 12、脚本 API 2，需要支持清单全部能力的 FluxDO 开发版本。授权初始化、回调交接、身份核验和订单流程由插件实现，通过应用公共 Connect、具名凭证和 LDC 收银台串联原生界面。

同源升级按账号迁移旧版未决提交记录，保留原提交号。自动化验证使用模拟授权和付款响应，真实账号与五平台设备仍需联调验收。

链接商品在详情页直接获取兑换地址，加载期间防止重复点击，失败提示与重试位于底部操作区。离开页面或切换后台后忽略晚到的打开结果。

## 安装

在 FluxDO 的更新设置中启用预览版本，再到「元宇宙 → 市场」搜索 LD士多，阅读权限后安装。也可从本仓库 Release 下载 `.fluxplugin`，在应用的添加服务入口选择文件。

## 权限与数据

商品和订单数据通过清单声明的士多接口读取。授权由当前 Linux DO 账号发起，凭证绑定当前账号。LDC 付款使用应用收银台，提交前由用户确认。

插件使用原生组件库，跟随应用主题。详情页面按界面实例保存状态，返回时保留筛选和分页。日志、占用空间与数据重置入口位于插件管理。

## 开发

`plugin.json` 声明能力。修改 `src/main.js`、`src/ui.rfwtxt` 和 `locales/` 词典 后生成本地化文件；根目录的 `main.js` 与 `ui.rfwtxt` 是打包产物，不直接编辑。界面支持简体、台湾繁体、香港繁体和英文，服务内容与用户输入保持原文。

```sh
node tools/localize.mjs
node tools/package.mjs plugins/ld-store dist/ld-store-2.7.1.fluxplugin
```

测试与宿主实现见 [FluxDO](https://github.com/Lingyan000/fluxdo)。


## 买家功能

- 登录前阅读服务条款并主动勾选同意；随后由宿主单独确认 Connect 账号授权。
- 原生收藏及分页搜索、发表评论与符合资格的评分、评论回复与赞踩、确认后删除有权限的评论。
- 售罄发卡商品可订阅补货通知；商品和评论可提交举报，并查看处理记录、补充文字和申请复核。
- 领券和我的优惠券、退款申请与售后进度。
- 店铺券按商户身份打开原生商品列表；订单券直接进入占用/使用订单。
- 商品网格采用宿主 GridPage，按视口构建，同行卡片等高。
- 安装前校验所需宿主能力，新增权限在升级时确认；2.6.0 的评论删除增加限定评论路径的 `DELETE` 权限。

条款入口与业务协议来自士多公开前端。所有接口测试使用本地响应，未使用真实账号提交付款、评论或退款。真实账户联调由维护者验收。

`node --test tools/ld-store.test.mjs` 覆盖协议取消、Connect 取消、收藏、评分限制、优惠券、售后与重复提交控制。退款请求失败后只查询服务状态，不自动再次 POST。

## 展示与交互

整卡进入商城，卡片内容显示统计。商品列表采用固定搜索和横向分类，筛选在独立弹层确认后应用。详情增加主题金额、折扣、库存销量、卖家入口、受控 Markdown 和图片预览；购买资格按服务数据判断。订单提供金额明细、时间线、默认隐藏的交付内容、复制和重新兑换，可见待处理订单定时核对。系统消息支持原生分页、筛选、标记已读和关联页面跳转。

请先更新 FluxDO。登录和付款可在操作时申请缺失权限。权限管理位于卡片菜单和插件管理。卖家后台、求购会话仍在网站，可能需要单独登录。插件不会向网页注入令牌；举报核查与退款是独立流程。

`previews/` 为原生组件测试生成的模拟数据截图，包含图片加载失败的占位状态，不代表真实商品或真实交易。

## 标题栏与统计加载

筛选、我的士多、收藏、订单刷新及消息操作使用宿主的标题栏插槽，与正文共享状态。商品列表同时显示折扣、原价、库存和已售数量，发货类型与卖家合并一行。详情主操作靠右，确认兑换占满底部可用宽度。服务卡片整卡可点击，统计加载使用骨架，刷新失败保留上次成功的数据并提示。

系统消息通过 SSE 同步未读统计；隐藏时暂停，重连后补查。请先更新支持 `pageChrome` 的宿主，再从原来源更新插件，旧宿主会提示能力不兼容。

## 后台提醒与证据图片

「我的士多 → 消息提醒」分别开启定时检查与系统通知，缺失权限会在操作时申请。首次只记录基线，后续根据消息 ID 和服务端时间去重，并更新已添加到导航的商城角标。约 15 分钟是系统调度期望，应用被强制停止后不运行。系统通知关闭不影响消息查询。

举报详情可选择 PNG/JPEG/WebP 证据（单张至多 5 MiB，最多 3 张），预览后明确点击上传。上传显示进度并可取消，失败保留原操作号供核对后重试，不自动重复提交。私密图片经具名凭证读取，不注入网页，不写入公开图片缓存。

升级增加后台和通知声明，旧版本不会自动取得权限。已登录的唯一账号可继承原存储分区，无法可靠归属的旧数据保留而不暴露给其他账号。GitHub Release 与市场均为预览渠道。
